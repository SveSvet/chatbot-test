### Тестовое: простой чат с ботом (React+TS + мини-API)

Реализовать простой чат, где пользователь вводит текст, 
видит своё сообщение, а бот отвечает тем же текстом с задержкой. 
- Минимальный внешний вид;
- Запуск локально, можно предусмотреть деплой;
- Желателен реалистичный API;

1) План
- Эхо-бот, задержка ответа на сервере ~800–1200 мс
- UI минимальный: список сообщений, поле ввода, 
кнопка «Отправить». Разделение «user / bot» визуально (простая верстка)
- Блокировать пустые сообщения
- Ограничение длины не вводим (только trim)

Локальный запуск: фронт - Vite/CRA (React + TS), сервер - Node + Express

2) Критерии готовности
- Ввод текста → сообщение появляется в списке сразу
- Через ~1с приходит ответ бота с тем же текстом
- Enter отправляет, Shift+Enter - перенос строки
- Пустые строки не отправляются 
- При недоступном сервере - локальная реальзация с setTimeout и уведомление об оффлайне
