## Test Chat

Небольшой чат-бот в стиле Windows XP.  
Клиентская часть написана на **React + TypeScript + Vite**, серверная — на **Node.js**.

### Возможности
- Отправка сообщений пользователем
- Ответы бота с задержкой в 1000 мс
- Минималистичная стилизация в стиле Windows XP

## Запуск

### 1. Установка зависимостей
Перейдите в нужную папку и установите зависимости:

```bash
cd client
npm install

cd ../server
npm install
```

### 2. Запуск серверной части
```
cd server
npm run server
```

###3. Запуск клиентской части
В другом терминале:
```
cd client
npm run dev
```

После этого фронт будет доступен по адресу:
http://localhost:3000

а API работает на:
http://localhost:8000/api
